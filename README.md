# MrChloro: Chloroplast Assembly Pipeline

A Nextflow pipeline engineered for the automated assembly, standardization, and polishing of chloroplast genomes from highly fragmented or complex Illumina reads. Utilizing automated fallback logic, the pipeline leverages GetOrganelle for primary assembly, seamlessly routing incomplete scaffolds to NOVOPlasty for targeted extension and completion.

Fully containerized tool; no need to pre-download or install any files, tools, or dependencies other than those which are typically already installed in an HPC cluster (or Docker, if running locally or via AWS). See **Dependencies** section.

## Pipeline Architecture

MrChloro features an asynchronous, non-blocking workflow with fast-track/slow-track routing, ensuring that samples that assemble quickly are not delayed by problematic samples requiring rescue. It also features file-size filtering to ensure only high-quality assemblies proceed to polishing.

The pipeline can be run in two modes:

### Mode 1: Full Assembly & Polishing (Default)
1. **Quality Control:** Fastp to trim adapters out of raw reads.
2. **Primary Assembly:** GetOrganelle for initial assembly attempt.
3. **Secondary Assembly/Rescue (Slow Track):** If no complete genome is generated by GetOrganelle, the pipeline routes the incomplete scaffold to NOVOPlasty for targeted extension (automatically inverted if orientation does not match the standard).
4. **Standardization:** Automated decision logic to rotate assemblies to a uniform starting position and select the correct isomer (if isomers present).
5. **Polishing:** BWA-MEM2 mapping of trimmed reads to the standardized assembly, followed by Pilon consensus correction.
6. **Re-mapping:** If Pilon produced changes, BWA-MEM2 mapping of reads to the new, polished genome.
7. **Statistics:** SAMtools to get basic statistics (e.g.: average depth of coverage) of the final, polished assembly.

### Mode 2: Polish-Only Mode
1. **Quality Control:** Fastp to trim adapters out of raw reads.
2. **Bypass Assembly:** Skips GetOrganelle, NOVOPlasty, and Standardization.
3. **Direct Polishing:** Maps trimmed reads directly to user-provided, pre-assembled `.fasta` genomes using BWA-MEM2 and polishes via Pilon.

## Quick Start

You do not need to clone this repository manually. Nextflow will handle the download and execution automatically. 

**Run on a local machine (requires Docker):**
```bash
nextflow run martinbatalla/mr_chloro -profile standard --input_dir /path/to/reads --ref_seed /path/to/seed.fasta --ref_gb /path/to/reference.gb
```

**Run on an HPC cluster (requires Singularity & SLURM):**
*Note: MrChloro automatically manages Singularity images, routing them to `$HOME/singularity_images` to prevent quota overages.*
```bash
nextflow run martinbatalla/mr_chloro -profile hpc --input_dir /path/to/reads --ref_seed /path/to/seed.fasta --ref_gb /path/to/reference.gb
```

**Run on AWS Cloud (requires AWS Batch):**
```bash
nextflow run martinbatalla/mr_chloro -profile aws --input_dir s3://your-bucket/reads --ref_seed s3://your-bucket/seed.fasta --ref_gb s3://your-bucket/reference.gb --out_dir s3://your-bucket/results
```

**Run Polish-Only Mode (Skips Assembly; HPC example):**
```bash
nextflow run martinbatalla/mr_chloro -profile hpc --polish_only true --input_dir /path/to/reads --assemblies_dir /path/to/fastas --ref_gb /path/to/reference.gb
```

## Dependencies

You do **not** need to install any bioinformatics tools (BWA, GetOrganelle, NOVOPlasty, etc.) locally. The pipeline is fully containerized. You only need:
* [Nextflow](https://www.nextflow.io/docs/latest/getstarted.html) (version 23.10.1 or later recommended)
* Docker (for local/AWS execution) OR Singularity (for HPC execution)

If running via an HPC cluster, Nextflow and dependencies are usually already installed, although they may need to be loaded by user (e.g.: `module load nextflow`).

## Parameters

| Parameter | Description |
|-----------|-------------|
| `--input_dir` | Path to the directory containing paired-end fastq files (must end in `_R1_001.fastq.gz` and `_R2_001.fastq.gz`). |
| `--ref_gb` | Path to GenBank (`.gb`) reference file used for standardizing the starting position. |
| `--ref_seed` | (Required for Assembly mode) Path to `.fasta` seed file used for NOVOPlasty and GetOrganelle orientation. |
| `--polish_only` | (Optional) Boolean flag to skip assembly steps and run polishing only. Default: `false`. |
| `--assemblies_dir` | (Required if `--polish_only true`) Path to the directory containing pre-assembled `${sample_id}_raw.fasta` files. |
| `--out_dir` | (Optional) Directory where results will be saved. Default: `results/`. |
| `--cpus` | (Optional) Number of CPUs assigned to processes. Default: local/AWS = 6, hpc = 16 |
| `--memory` | (Optional) Memory allocated to processes. Default: local/AWS = '8 GB', hpc = '64 GB' |
| `--fastp_cpus` | (Optional) Number of CPUs assigned to Fastp (having too many may prevent threads from closing and freeze the whole pipeline). Default: local/AWS = 6, hpc = 8 |
| `--fastp_memory` | (Optional) Memory allocated to Fastp. Default: local/AWS = '8 GB', hpc = '32 GB' |

## Pipeline Outputs

When the pipeline finishes, your output directory will contain a folder for each sample ID. Inside, you will find:
* **HTML/JSON quality reports:** Output of Fastp to check quality of trimming reads. Trimmed read files are not saved to save space.
* **`${sample_id}_cpDNA_raw.fasta`:** Raw, pre-polished assembly of genome as generated by GetOrganelle or NOVOPlasty (Assembly mode only).
* **`${sample_id}_cpDNA_polished.fasta`:** Final, polished `.fasta` assembly.
* **`${sample_id}_coverage.txt`:** A `.txt` with basic stats of assembly, including the average depth of coverage.

If NOVOPlasty was run, additional outputs may include:
* **`${sample_id}_seed.fasta`:** Best scaffold output by GetOrganelle used as a seed to extend in NOVOPlasty.
* **`Circularized_assembly_[1-9]_${sample_id}.fasta`:** Circularized genome generated by NOVOPlasty.
* **`Contigs_[1-9]_${sample_id}.fasta`:** Contigs generated by NOVOPlasty.
* **`Option_[1-9]_${sample_id}.fasta`:** Circularized genomes generated by NOVOPlasty. When multiple options are present, these mostly display different orientations of the SSC (MrChloro selects the best one).
